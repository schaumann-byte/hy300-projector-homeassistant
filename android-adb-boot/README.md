# ADB Boot

> *Generated by [aurora@aurora-smart-home (ha-integration-dev skill)](https://github.com/tonylofgren/aurora-smart-home)*

A minimal Android app (`br.casa.adbboot`, ~12 KB) with no UI, no launcher icon and no INTERNET permission. It exists to fix two boot-time problems on HY300 / Magcubic projectors (Android 14):

1. **Wireless debugging turns itself off on every reboot.** Android 11+ resets `adb_wifi_enabled` to 0. On `BOOT_COMPLETED` the app sets it back to 1, and does it again from a `JobScheduler` job once a network is up, so remote ADB returns by itself about a minute after power-on.
2. **The vendor launcher always shows up at boot.** `com.htc.magcubicos` is a direct-boot-aware system app, so the system starts it before any user-chosen launcher. The app sends a `HOME` intent at `BOOT_COMPLETED` and again 5 s later, inside `goAsync()`, which brings your default launcher (e.g. Projectivity) to the front.
   - A `Handler.postDelayed` after `onReceive` does **not** work, because Android 14 freezes the cached process first.

## Permissions (granted once over adb)

```sh
adb install -r adbboot.apk
adb shell pm grant br.casa.adbboot android.permission.WRITE_SECURE_SETTINGS   # write adb_wifi_enabled
adb shell appops set br.casa.adbboot SYSTEM_ALERT_WINDOW allow                # start HOME from background
adb shell am broadcast -n br.casa.adbboot/.BootReceiver                       # leave "stopped" state once
```

Check after a reboot: `adb logcat -d -s AdbBoot:*` should show `adb_wifi_enabled=1 (android.intent.action.BOOT_COMPLETED)`.

## Build

No Android Studio needed. The build runs in a JDK container and downloads the official command-line tools on first run (cached in `.sdk/`):

```sh
podman run --rm -v "$PWD":/work:Z -v "$PWD/.sdk":/sdk:Z docker.io/library/eclipse-temurin:17-jdk sh /work/build.sh
```

Signing uses `KEYSTORE` / `KS_PASS` if set, otherwise a throwaway local key is generated on the first build. Updates must be signed with the same key as the installed app. Otherwise uninstall it first.

## Uninstall

`adb uninstall br.casa.adbboot`. Wireless debugging goes back to switching off on reboot.
